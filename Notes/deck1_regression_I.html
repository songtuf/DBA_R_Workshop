Why Regression?

The workhorse of business research

  • Open any issue of JMR, Marketing Science, or JM: the headline evidence is very often a regression table
  • Research questions of the form: “How is Y related to X, holding everything else constant?”
  • Today: run it and read it. Tomorrow: interrogate it.

Show 2–3 journal abstracts/tables here (screenshots). Pick your own go-to papers; read one DV + one coefficient aloud.

When to use multiple regression

  • Outcome (Y): one continuous variable
  • Predictors (X): any mix — continuous, categorical, many of them
  • Question: association between each X and Y, adjusting for the others
  • Not (yet) a causal claim — that conversation is tomorrow

A Little Theory (No Proofs)

The model

\[\text{sales}_i = \beta_0 + \beta_1\,\text{ad\_spend}_i + \beta_2\,\text{price}_i + \varepsilon_i\]

  • The model describes the conditional mean of Y given the Xs
  • \(\beta_k\): expected change in Y for a one-unit change in \(X_k\), holding the other Xs constant
  • “Holding constant” is the entire point of multiple regression

How the line is chosen: OLS

  • OLS picks the \(\beta\)s that minimize the sum of squared residuals
  • Residual = actual − predicted: what the model missed

One intuitive picture; no derivation. “Best” has a precise meaning — we give it a name (BLUE) tomorrow.

Mis-interpretation check ❌

Would a reviewer let these through?

  1. “Ad spend drives sales up by 100 units.”
  2. “The model explains 60% of sales.”
  3. “Price is not significant, so price has no effect.”
  1. causal verb from observational data; (2) variance ≠ level;
  2. absence of evidence ≠ evidence of absence. Recurring segment — same game appears on quizzes.

  • R picks a reference category (first level: Southeast)
  • Each coefficient = that region vs. the reference, holding the rest constant

Output → Sentence

“Compared with Southeast stores (the reference), Northeast stores sell about ___ more units per week, holding ad spend, price, and store size constant.”

  • Changing the reference changes the coefficients, not the model
  • relevel() demo: same fit, different comparisons

Standardized vs. unstandardized

m2_std <- lm(scale(sales) ~ scale(ad_spend) + scale(price) +
             scale(store_size) + region, data = storemax)
  • Unstandardized: real units → best for substantive sentences
  • Standardized: SD units → comparing relative importance within a model
  • Never compare standardized βs across different samples/models
